# Sally 3D avatar model provenance

`sally_avatar.glb` is the Avaturn female demonstration avatar from the
open-source TalkingHead project:

- Source: https://github.com/met4citizen/TalkingHead/blob/main/avatars/avaturn.glb
- Project license: MIT
- Retrieved: 2026-09-11

The model is stored locally so the video-call experience has no runtime
dependency on a third-party avatar CDN. Sally IP's rendering, state animation,
gaze, blinking, and audio-driven viseme code is implemented locally.
