Prior-art search that shows its mapping

A prior-art search is only as good as its mapping: which passage anticipates which limitation, and what is still missing. SallyIP structures every search as a reviewable claim-to-evidence matrix.

How a strong search runs

  1. Knockout: exact anticipations first — one reference disclosing every element ends the inquiry early.
  2. Expansion: synonyms, classifications and citation-graph neighbors across EPO, USPTO and literature sources.
  3. Mapping: each claim limitation against retrieved passages, with gaps explicit — unmapped limitations are findings, not omissions.
  4. Families and timelines: priority dates and prosecution history set what counts as art and when.

What AI contributes

Retrieval breadth, paraphrase-robust matching, and structured matrices a practitioner reviews — including the invented-step combinations the search surfaces for obviousness analysis. Final patentability judgment stays with counsel.

Sources and coverage

Searches run across EPO, USPTO and EUIPO official sources plus harvested literature, with provider status reported honestly — when a source is unreachable, the run says so instead of simulating results. Every official-search run is persisted with its audit trail, so a search can be re-run and its coverage challenged later.

Reading a mapping

Each matrix row pairs one claim limitation with the passages that disclose it, the passages that come close, and the limitations with nothing found. Unmapped limitations are findings in their own right: they narrow where the novelty lives and where drafting should reinforce support. Gaps are never filled with model knowledge.

Why missed art is expensive

An anticipation found during prosecution costs an amendment; the same reference found in litigation can cost the patent. Search quality compounds: the matrix from this search becomes the novelty argument, the FTO baseline, and the prosecution record. That is why every row links to its passage — a mapping nobody can inspect is a conclusion nobody should rely on.
