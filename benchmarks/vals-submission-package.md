## 1. Product summary
- SallyIP is an evidence-first patent-IP assistant: hybrid retrieval (lexical + pack fallback + section refs + concept aliases) over US/IN/GB jurisdiction packs; citation labels (`[S1]`…) enforced by `guardAnswerCitations` (fail-closed on dangling citations); verbatim quote verification (`verifyQuote`, `auditAnswerQuotes`: bracket/citation/markdown conventions, `...` ellipsis segments, prompt-echo + grounded-denial exemptions — every checked word still verbatim in one source); proposition entailment (`checkEntailment`) + citation ledger (`answer_citations`, `proposition_sources`); adversarial posture (abstain/correct-premise on fake authorities, fee specifics, unanswerable specifics); offline patent-intelligence layer (publication-number parsing, biblio preservation, family grouping, duplicate collapse, false-merge resistance).
- What it is NOT: not a certified legal-opinion generator; not practitioner-validated (0/25 graded); P0 release gates currently FAIL so production stays on the pre-change build (`benchmarks/regression_report_p0_full.md`).
